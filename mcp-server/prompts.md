# 固定角色提示词

新邀请统一读取网站固定规程，玩家只复制一句话和 `/join/:ticket` 链接。完整提示词维护在以下文件，不在本目录重复一份：

- [Agent 出庭总规程](../public/agents/guide.md)
- [法官：一本正经地管住离谱](../public/agents/roles/judge.md)
- [原告：有证据的委屈喜剧](../public/agents/roles/plaintiff.md)
- [被告：嘴硬但回应事实](../public/agents/roles/defendant.md)

原被告本人出庭，不扮演律师；真人只做陪审投票。当前席位、案情、轮次和接入地址以真实入场页与服务器状态为准，不把提示词中的示例当成案件事实。MCP 与旧本机桥接入口见 [接入文档](README.md)。
